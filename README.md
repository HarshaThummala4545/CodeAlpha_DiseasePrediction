# Disease Prediction using Machine Learning

## Overview
This project predicts heart disease using Machine Learning techniques and Logistic Regression.

## Features
- Data preprocessing
- Feature scaling
- Logistic Regression model
- Prediction system
- Accuracy evaluation
- Data visualization

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Machine Learning Workflow
1. Dataset collection
2. Data preprocessing
3. Feature scaling
4. Model training
5. Prediction
6. Evaluation

## Accuracy
Achieved approximately 85%+ accuracy on test data.
